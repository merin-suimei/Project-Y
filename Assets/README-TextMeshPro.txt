Поскольку папка TextMesh Pro находится в .gitignore, в первый раз её нужно импортировать вручную

Варианты импорта:
1) Открыть любую сцену, где используется TextMesh Pro (на пример CreditsScene) и в появившемся окне нажать "Import TMP Essentials", закрыть окно импорта

2) Из любой сцены. В верхней панели редактора прожать Window -> TextMeshPro -> Import TMP Essential Resources, нажать "Import" в появившемся окне
