Поскольку папка TextMesh Pro находится в .gitignore, в первый раз её нужно импортировать вручную

Процесс импорта:
1) Открыть любую сцену, где используется TextMesh Pro (на пример CreditsScene)
2) В появившемся окне нажать "Import TMP Essentials"
3) Закрыть окно импорта

Важно: Добавление через [Window -> TextMeshPro -> Import TMP Essential Resources] не добавляет кириллицу
